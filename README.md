# Precipitating System Tracking Analysis

## Overview

This project investigates the characteristics and long-term trends of precipitating systems using four key variables: **count, size, intensity, and duration**. 
The analyses are conducted at three levels to characterize overall behavior and assess differences across geographic regions and land-cover types.

## Analysis

### 1. Full Dataset Analysis
Analysis of the complete dataset (variability, distributions, and long-term trends) over the entire domain.

### 2. Regional Analysis
Analysis subdivided by geographic region: **northern and southern regions**.

### 3. Land-Cover Analysis
Analysis subdivided by land-cover type: **forest and non-forest areas**.

## Variables

The following variables are investigated across all three analysis categories:

- **Count:** Number of unique systems (n).
- **Size:** Effective Radius (km).
- **Intensity:** Rain rate intensity (mm/hr).
- **Duration:** Lifetime (hr).
